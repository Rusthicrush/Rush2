What it does

Four jobs, running quietly in the background

No dashboard to babysit. It watches your chats and acts the moment something happens.

💬

Auto‑reply

Recognizes 90+ everyday keywords and shorthand — Tanglish included — and replies instantly, even offline chats.

🗑️

Anti‑delete

Captures the message, sender's name, and photo the instant it arrives — so a "deleted for everyone" never actually is.

📥

Status saver

Auto‑views contacts' statuses and forwards a copy — text, photo, or video — straight to your own chat.

🎵

Media tools

.yt pulls audio from a song name or link. .img finds a picture on request. Right in the chat.

Talk to it directly

Setup

From zip to linked device

Runs entirely inside Termux. No PC, no Android Studio, no server.

Install Termux tools

pkg install -y yt-dlp ffmpeg

Node.js installs itself on first run.

Unzip the project

unzip rushsync-final.zip

Extracts into a rushsync/ folder. Don't have the zip yet? Download it here.

Start it up

cd rushsync && bash start.sh

First run installs dependencies automatically.

Link your number

WhatsApp → Linked Devices

Enter the pairing code shown in the terminal.
